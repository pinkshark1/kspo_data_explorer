# 공용 무료 AI Claude 우선 호출 공개 화면 확인 (2026-10-15)

공용 중계 서버에 Claude를 켠 뒤, 공개 화면에서 API 키를 넣지 않고 ‘질문 검색 → AI 추천 (Claude·Gemini)’을 실제로 호출해 확인한 기록입니다. 일반 Chrome 창을 자동화 도구(Playwright)로 조작해 질문했고, 이용 확인 상자는 누르지 않았습니다. 중계 서버 응답의 상태·`X-AI-Provider` 헤더·응답 시간은 브라우저가 기록한 값을, 화면 결과는 화면에 나온 그대로 옮겼습니다. 질문 외의 요청 내용, API 키, 이용 확인 토큰은 기록하지 않았습니다.

| 항목 | 값 |
|---|---|
| 확인일 | 2026-10-15 (한국 시간) |
| 화면 | 공개 웹 화면 (GitLab `main` → GitHub Pages 배포본, 소스 커밋 18be5b4) |
| 중계 서버 | 같은 커밋의 `server/shared-ai-worker.js`를 배포하고 Secret `ANTHROPIC_API_KEY`와 확인값 `ANTHROPIC_CREDITS_ONLY_CONFIRMED=true`를 설정 |
| 호출 경로 | 브라우저 → 이용 확인(Cloudflare Turnstile) → 공용 중계(Cloudflare Workers 무료 플랜) → Anthropic Claude API (실패 시 Google Gemini API) |
| 모델 | Claude Haiku 5.5 (`claude-haiku-5-5`, effort `low`). 예비 모델 Gemini 3.5 Flash-Lite (`gemini-3.5-flash-lite`) |
| 이용자 키 | 없음 (키 입력란을 열지 않음) |

## 1. 증빙용 호출

| 시각 | 질문 (입력한 곳) | 중계 응답 | `X-AI-Provider` | 응답 시간 | 화면 |
|---|---|---|---|---|---|
| 16:02:53 | 동네 체육시설의 안전점검 결과와 위치를 함께 분석할 수 있는 공공데이터를 알려줘 (‘질문 검색’ 메뉴) | 200 | `claude` | 6.9초 | 오류 안내 없음. AI 안내 + AI가 고른 데이터 8건 + 함께 활용하면 좋은 조합 2개 |
| 16:03:28 | 장애인 체육시설 위치 데이터 알려줘 (첫 화면 질문 칸) | 200 | `claude` | 5.7초 | 오류 안내 없음. AI 안내 + AI가 고른 데이터 6건 + 조합 1개 |

응답 시간은 브라우저가 중계 서버에 요청을 보내고 응답을 다 받을 때까지입니다. ‘질문하기’를 누른 뒤 결과가 나올 때까지는 이용 확인을 포함해 각각 21.3초, 9.5초가 걸렸습니다.

첫 질문은 [2026-10-13 기록](2026-10-13-shared-ai-live.md)(Gemini)과 같은 질문입니다.

- AI가 고른 데이터(관련도): 전국체육시설 안전점검 정보(높음), 전국공공체육시설 데이터(높음), 전국체육시설 정보(보통), 전국체육시설현황 데이터(보통), 체육시설 안전점검 결함사진 학습 데이터(보통), 체육시설안전점검정보(보통), 체육시설 인접 대중교통 정보(참고), 공공체육시설 상세 정보_GW(참고). 10-13에 Gemini가 고른 4건이 모두 들어 있습니다.
- AI 안내: “동네 체육시설의 안전점검 결과와 위치를 함께 보려면 체육시설 안전관리시스템(SFMS) 기반의 전국체육시설 안전점검 정보(170번)와 체육시설 위치 정보(전국공공체육시설 데이터 79번, 전국체육시설 정보 154번)를 함께 보시면 됩니다. 안전점검과 위치를 한 데이터에서 함께 제공하는지는 각 데이터 명세에서 확인하시기 바랍니다.”
- 조합: 안전점검 결과와 시설 위치 결합, 시설 위치 기반 주변 교통 분석

둘째 질문에서 AI가 고른 데이터(관련도)는 장애인스포츠강좌이용권시설정보(높음), 장애인스포츠강좌이용권 등록시설 정보(높음), 내주변문화지도연계장애인스포츠강좌이용권시설정보(보통), 장애인스포츠강좌이용권시설인근편의시설정보(보통), 스포츠강좌이용권시설 인접 대중교통 정보(보통), 지역별 장애인 생활체육 활성 정보(참고)이고, 조합은 ‘장애인 체육시설 위치와 편의시설 함께 보기’입니다.

두 질문 모두 공단이 개방한 192건 안의 데이터만 나왔습니다.

## 2. 같은 날 이용 확인 실패와 원인 확인

Claude를 켠 직후 담당자가 공개 화면에서 ‘공용 무료 AI 이용 확인을 완료하지 못했습니다. 잠시 후 다시 시도해 주세요. 기본 검색 결과를 대신 보여드립니다.’ 안내를 받았습니다. 이 안내는 중계 서버를 부르기 전, 이용 확인(Cloudflare Turnstile) 단계가 실패했을 때 나옵니다. 원인을 찾으려고 15:17~15:50에 위와 같은 방식으로 17번 질문했습니다. 이때는 Turnstile 호출을 기록하는 진단 스크립트를 브라우저에 더했습니다.

| 결과 | 횟수 | 내용 |
|---|---|---|
| Claude 응답 | 9 | 이용 확인을 통과했고, 중계 서버가 모두 200·`X-AI-Provider: claude`로 답함(추천 건수를 기록한 7번은 AI가 고른 데이터 3~8건). 그중 3번은 원인 비교를 위해 이 브라우저에서만 이용 확인 상자를 늘 보이게 바꾼 화면 코드로 질문함 |
| 이용 확인 실패 | 8 | 중계 서버를 부르지 않았고, 화면은 위 안내와 기본 검색 결과를 보여 줌. 모두 15:17~15:46에 ‘질문 검색’ 메뉴에서 질문한 경우. 기록된 오류는 Turnstile 오류 코드 300030이 3번, 확인 프레임 안의 스크립트 오류가 2번이고, 3번은 오류 내용을 기록하지 못함. 8번 중 1번은 2026-10-13 배포본의 화면 코드로, 1번은 이용 확인 상자를 입력 양식 밖으로 옮긴 화면으로 질문함 |

- 2026-10-13 배포본의 화면 코드로 바꿔 끼워도 같은 시간대에 같은 오류(300030)가 났습니다. 실패는 중계 서버를 부르기 전 단계이고 이번에 이용 확인 코드는 바꾸지 않았으므로, 이번 Claude 변경 때문은 아닌 것으로 봅니다.
- 15:47 이후에는 ‘질문 검색’ 메뉴를 포함해, 위 증빙용 2번까지 8번 모두 통과했습니다. Cloudflare 쪽 원인은 확인하지 못했습니다.

## 3. 비용

담당자가 16시쯤 Anthropic Console에서 확인한 사용액은 약 0.02달러(Claude Haiku 5.5)였습니다. 요청 수는 처음에 표시되지 않았다가 1건으로 나왔는데, 그때까지의 Claude 응답 수(9번)와 맞지 않아(원인 미확인) 요청당 비용은 계산하지 않았습니다.

## 한계

- Claude가 실패해 Gemini로 넘어가는 경우(크레딧 소진 `billing_error`, 20초 초과, 오류)는 실제로 일으키지 않았습니다. 이 동작은 모의 응답 점검(`npm run check:shared-ai` 27/27)으로만 검증했습니다.
- 요청당 토큰(크레딧 사용량)은 측정하지 않았습니다.
- 추천 품질은 평가하지 않았습니다. 첫 질문에서 10-13 Gemini가 고른 데이터가 모두 들어 있는 것만 확인했습니다.
- 이용 확인 간헐 실패의 원인은 확인하지 못했습니다. 실패하면 화면은 기본 검색 결과로 전환합니다.
