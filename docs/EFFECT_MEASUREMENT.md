# 효과 측정 방법 (탐색 시간 비교)

README 의 ‘기대 효과’는 아직 측정한 수치가 없는 **기대**입니다. 실제 수치는 아래 방법으로 직접 측정한 값만 기재합니다.

## 측정 방법

1. **참여자**: 업무에서 공단 데이터를 찾아본 경험이 있는 직원 3~5명 (같은 사람이 두 방식을 모두 수행하면 순서를 번갈아 진행해 익숙함 효과를 줄입니다.)
2. **과제 3개**: 실제 업무에서 나올 법한 질문을 미리 정합니다. 예)
   - ‘스포츠강좌이용권 이용현황 데이터가 어느 포털에 있는지 찾고 원문 페이지까지 이동하기’
   - ‘체육시설 안전점검과 관련된 데이터 후보를 3개 이상 찾기’
   - ‘경륜 선수 정보 API의 응답 컬럼명 확인하기’
3. **방식 비교**: (가) 기존 방식 - 공공데이터포털·문화빅데이터포털에서 직접 검색 / (나) KSPO 데이터 지도
4. **측정값**: 과제별 소요 시간(초), 찾은 데이터가 정답 기준과 맞는지(정확 여부), 막힌 지점 메모
5. **기록 후 요약**: 아래 표에 채우고, 평균은 참여자 수가 적으므로 중앙값과 최소·최대를 함께 적습니다.

## 보고할 때 지켜야 할 것

- 측정하지 않은 수치(예: ‘탐색 시간 70% 단축’)는 쓰지 않습니다.
- 표본이 작다는 점(참여자 수, 과제 수)을 함께 밝힙니다.
- 측정일, 사용한 화면 버전(저장소 커밋), 데이터 기준일을 함께 적어 둡니다.
